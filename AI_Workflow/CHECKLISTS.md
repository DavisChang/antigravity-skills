# Checklists

## AI 專案啟動 Checklist

- [ ] 已明確定義 AI 要幫誰做什麼
- [ ] 已選定具體流程，而不是模糊職位
- [ ] 已畫出資料、邏輯、行動三欄
- [ ] 已識別 context bottleneck
- [ ] 已識別 capacity bottleneck
- [ ] 已蒐集至少 5 個真實案例
- [ ] 已找出至少 1 位關鍵專家參與設計
- [ ] 已整理最小工作手冊
- [ ] 已定義讀取、建議、執行三層授權
- [ ] 已設定人工覆核機制
- [ ] 已能記錄 AI 建議是否被採納
- [ ] 已能記錄拒絕與修正原因
- [ ] 已定義主指標，不只看節省人力
- [ ] 已有回滾方案
- [ ] 已安排角色重設討論
- [ ] 已規劃每週回顧節奏

## AI 輸出品質 Checklist

- [ ] 已說明判斷依據
- [ ] 已列出假設
- [ ] 已指出風險
- [ ] 已提供反例或不適用情境
- [ ] 已給出下一步
- [ ] 已避免只做摘要
- [ ] 已轉成可執行格式
- [ ] 已提供成功判準
- [ ] 已清楚標示需要人工確認的部分

## 決策品質 Checklist

- [ ] 已定義決策問題
- [ ] 已列出已知資料
- [ ] 已列出缺少資料
- [ ] 已定義判斷標準
- [ ] 已排序判斷標準的重要性
- [ ] 已列出至少 2 個可選方案
- [ ] 已比較每個方案的代價
- [ ] 已指出最大風險
- [ ] 已定義下一步行動
