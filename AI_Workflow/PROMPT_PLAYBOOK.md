# Prompt Playbook

這份文件收錄常用 prompt。使用時，把任務內容貼在 prompt 後方即可。

## 1. 知識萃取

```text
請不要只摘要。請把以下內容整理成可重複使用的知識資產。

請輸出：
1. 內容切片
2. 主題地圖
3. 每個主題的核心原則
4. 可操作做法
5. 適用情境
6. 風險與反例
7. 30-90 分鐘內可以測試的小實驗
8. 可直接放進 Notion 的 checklist
9. 下週可以執行的 experiment backlog
```

## 2. 決策分析

```text
請協助我做這個決策。

請先把問題拆成：
1. 資料：我目前知道什麼、還缺什麼
2. 邏輯：應該用哪些標準判斷
3. 行動：有哪些可選方案

接著請輸出：
- 你推薦的方案
- 推薦理由
- 最大風險
- 我可能忽略的盲點
- 下一步 3 個行動
```

## 3. 反方檢查

```text
請不要急著同意我。

請站在資深顧問、產品負責人、投資人、使用者的角度，挑戰以下想法。

請指出：
1. 哪些假設可能是錯的
2. 哪些地方證據不足
3. 哪些風險被低估
4. 哪些替代方案更簡單
5. 如果只能做一個小實驗，應該先測什麼
```

## 4. 實驗設計

```text
請把以下想法轉成一個可以下週執行的實驗。

請包含：
- 實驗目標
- 核心假設
- 執行步驟
- 需要的資源
- 成功判準
- 失敗後如何調整
- 90 分鐘內的最小版本
```

## 5. Playbook 產出

```text
請把以下內容整理成一份 playbook。

請包含：
1. 適用場景
2. 不適用場景
3. 前置條件
4. 操作步驟
5. 檢查點
6. 常見錯誤
7. 成功判準
8. 可複製模板
```

## 6. Checklist 產出

```text
請把以下流程轉成 checklist。

要求：
- 每一項都必須是可檢查的行動
- 不要寫抽象原則
- 每一項都用「已...」開頭
- 最後補上失敗風險與補救方式
```

## 7. 角色重設

```text
請協助我重新設計這個角色在 AI 協作下的工作方式。

請輸出：
1. 這個角色原本的主要工作
2. AI 可以承接或輔助的工作
3. 人必須保留的判斷工作
4. 人機協作的新工作流
5. 新增的高價值任務
6. 不應該再手動做的任務
7. 新的績效指標
8. 導入風險
```

## 8. 文件重寫

```text
請重寫以下文件，讓它更適合實際執行。

重寫要求：
- 保留原意
- 刪掉空泛語句
- 補上操作步驟
- 補上決策標準
- 補上風險與反例
- 補上下一步
```
